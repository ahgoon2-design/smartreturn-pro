# 고객사별 판정표/체크리스트/AI 판정도우미 정책

이 문서는 SmartReturn Pro의 반품 판정 지원 기준이다. AI는 최종 판정자가 아니라 판정지원 도우미이며, 최종 판정은 작업자가 확정한다.

## AI 방향

SmartReturn의 AI는 사진/영상 자동판별이 1차 목표가 아니다. 1차 목표는 고객사별 판정 매뉴얼과 판정표를 기준화하고, 작업자의 판정을 빠르고 일관되게 돕는 것이다.

사진/영상은 우선 아래 용도로 사용한다.

- 판정 증빙.
- 분쟁 대응.
- 고객사 확인.
- 작업자 교육자료.
- 향후 학습자료.

특정 고객사/특정 상품군/충분한 학습자료가 있을 때만 사진/영상 자동판별 실험을 제한적으로 검토한다.

## 추천 구조

```text
고객사별 판정표
+ 작업자 체크리스트
+ 과거 확정 이력
→ 추천 판정
→ 추천 이유
→ 확인할 항목
→ 다음 작업 안내
```

AI도우미는 추천과 설명만 제공한다. 저장, 처리완료, 라벨, 일마감, 재고반영은 기존 반품처리 저장 흐름과 backend 검증을 그대로 탄다.

## 고객사별 판정표

고객사별로 판정 항목과 조건이 다르므로 공통 고정 버튼만으로 처리하지 않는다.

예시:

- 양품: 미개봉, 구성품 완전, 판매 가능 상태.
- 리퍼A: 개봉 흔적 있음, 사용감 거의 없음, 재포장 후 판매 가능.
- 리퍼B: 사용 흔적 있음, 기능 정상, 할인 판매 가능.
- 제조사반출: 초기불량 의심, 기능불량, 제조사 확인 필요.
- 폐기: 파손 심함, 오염, 재판매 불가.
- 부품적출: 본체는 폐기 대상이나 재사용 가능한 부품이 있음.

## 체크리스트 후보

- 미개봉.
- 개봉.
- 박스훼손.
- 젖음.
- 스크래치.
- 깨짐.
- 오염.
- 구성품 누락.
- 빈박스.
- 오입고.
- 부품적출 가능.
- 업체확인 필요.

체크리스트는 고객사/상품군별로 다르게 구성할 수 있다. 작업자 화면에서는 체크 항목을 짧고 빠르게 선택할 수 있어야 한다.

## AI도우미 위치

관리 화면:

```text
고객사 관리
→ 반품 판정 설정
→ 판정표/체크리스트
```

작업자 화면:

```text
반품처리 화면 안의 기존 AI도우미 영역
```

새 AI 화면이나 새 AI 패널을 남발하지 않는다. 작업자가 운송장, 상품, 판정, 창고 확정 흐름 안에서 도움을 받도록 둔다.

## 플랜별 방향

- Basic: 고객사 기본 판정 항목과 단순 체크리스트 중심.
- Pro: 고객사별 판정표 기반 추천 판정과 추천 이유.
- Ultra: 과거 확정 이력, 세트/구성품/부품적출 가능성, 고급 추천 사유 확장.

## Codex 구현 전 체크

- AI가 최종 판정자로 구현되어 있지 않은가?
- 사진/영상 자동판별을 1차 목표로 삼고 있지 않은가?
- AI 추천이 기존 반품처리 저장/검증 흐름을 우회하지 않는가?
- 고객사별 판정표와 체크리스트 기준을 우선하는가?
- 작업자 화면에 AI 영역을 과도하게 키워 핵심 그리드와 판정 버튼을 밀어내지 않는가?
