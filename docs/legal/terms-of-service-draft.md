# SmartReturn-platform 이용약관 초안

> 본 문서는 운영정책 및 법무 검토 전 초안이며, 외부 공개 전 최종 검토가 필요합니다.

## 1. 외부 공개 후보 본문

### 1. 목적

이 약관은 SmartReturn-platform이 제공하는 반품처리, 택배 수거·배송조회, 센터 입고, 검수·판정, 사진·첨부파일 관리, 재고 반영, 정산 보조, API 연동 및 관련 서비스의 이용 조건과 절차, 회사와 이용자의 권리·의무 및 책임 사항을 정하는 것을 목적으로 한다.

### 2. 용어의 정의

이 약관에서 사용하는 용어의 뜻은 다음과 같다.

| 용어 | 정의 |
| --- | --- |
| 회사 | SmartReturn-platform 서비스를 제공·운영하는 주체 |
| 서비스 | 회사가 제공하는 반품처리, 물류 운영, 계정·권한, 통계·리포트, API 연동, 알림, 정산 보조 기능 |
| 이용자 | 고객사/쇼핑몰, 고객사 관리자, 대리점 담당자, 직영센터 담당자 등 서비스 계정을 부여받아 서비스를 이용하는 자 |
| 고객사/쇼핑몰 | 반품 접수, 상품, 주문, 정산, 고객문의 등 업무 데이터를 등록하거나 조회하는 계약 또는 운영 주체 |
| 고객사 관리자 | 고객사/쇼핑몰 소속으로 계정, 권한, 반품 자료, 정산 자료를 관리하는 이용자 |
| 대리점 담당자 | 관할 고객사와 반품 처리 업무를 관리하는 이용자 |
| 직영센터 담당자 | 배정된 반품의 입고, 검수, 판정, 사진·첨부파일, 반출 등 현장 업무를 처리하는 이용자 |
| 플랫폼 운영자 | 서비스 운영, 장애 대응, 보안, 고객지원, 정산 보조, 권한 관리 업무를 수행하는 회사의 권한자 |
| 외부 연동 주체 | 택배사, 외부 API, 알림 발송, 클라우드, 모니터링 등 서비스 제공을 위해 연동되는 외부 시스템 또는 업체 |
| 최종 고객/수취인 | 반품 상품의 수취인 또는 반품 신청자로서 직접 서비스 회원이 아닐 수 있는 정보주체 |
| 반품 처리 정보 | 반품 접수, 운송장번호, 상품명/옵션/수량, 입고, 검수, 판정, 사진, 첨부파일, 재고, 반출, 정산, 처리 이력에 관한 정보 |
| 계정 | 서비스 이용을 위해 부여되는 ID, 권한, 인증 정보 |
| API | 회사 또는 외부 시스템 간 데이터 연동을 위해 제공되거나 연결되는 프로그램 인터페이스 |

### 3. 약관의 게시와 개정

회사는 이용자가 쉽게 확인할 수 있도록 서비스 화면 또는 연결 화면에 이 약관을 게시한다.

회사는 관계 법령을 준수하는 범위에서 이 약관을 개정할 수 있다. 약관을 개정하는 경우 적용일자와 개정 내용을 서비스 화면 또는 공지사항을 통해 안내한다. 이용자에게 중요한 영향을 미치는 변경은 합리적인 기간을 두고 안내한다.

이용자가 개정 약관의 적용일 이후 서비스를 계속 이용하는 경우 개정 약관에 동의한 것으로 볼 수 있다. 다만, 관계 법령 또는 개별 계약에서 별도 절차를 요구하는 경우 그 절차를 따른다.

### 4. 약관 외 준칙

이 약관에서 정하지 않은 사항은 관련 법령, 개인정보처리방침, 서비스 화면의 운영정책, 개별 계약, 회사가 별도로 고지한 기준에 따른다.

개별 계약과 이 약관의 내용이 서로 다른 경우 개별 계약에서 정한 사항이 우선 적용된다. 개인정보 처리에 관한 사항은 개인정보처리방침을 우선 참조한다.

### 5. 이용계약의 성립

이용계약은 고객사/쇼핑몰, 대리점, 직영센터 등 이용을 신청하는 주체가 회사가 정한 방식으로 이용을 신청하고 회사가 이를 승낙함으로써 성립한다.

회사는 이용계약 성립 후 고객사, 대리점, 직영센터, 사용자 역할, 기능 범위, 이용요금, 정산 기준, API 연동 범위 등을 개별 계약 또는 서비스 설정에 따라 부여할 수 있다.

### 6. 이용신청의 승낙 및 제한

회사는 이용신청 내용, 계약 관계, 업무 범위, 권한 구조, 서비스 운영 가능 여부를 확인한 후 이용신청을 승낙할 수 있다.

회사는 다음 각 호에 해당하는 경우 이용신청을 승낙하지 않거나 승낙 후 이용을 제한할 수 있다.

1. 허위 정보 또는 타인의 정보를 사용하여 신청한 경우
2. 계약상 이용 권한이 확인되지 않는 경우
3. 서비스 운영 또는 보안에 중대한 지장을 줄 수 있는 경우
4. 법령, 약관, 운영정책을 위반한 이력이 있는 경우
5. 고객사, 대리점, 직영센터의 권한 범위가 확인되지 않는 경우
6. 회사가 요구한 필수 정보를 제공하지 않은 경우

### 7. 계정 및 권한 관리

이용자는 부여받은 계정과 인증 정보를 선량한 관리자의 주의로 관리해야 하며, 계정을 타인과 공유하거나 양도할 수 없다.

고객사 관리자, 대리점 담당자, 직영센터 담당자는 소속 조직의 이용자 권한이 실제 업무 범위와 일치하도록 관리해야 한다. 담당자 변경, 퇴사, 위탁 종료, 계약 종료 등으로 권한 회수가 필요한 경우 지체 없이 계정 비활성화 또는 권한 회수 조치를 해야 한다.

회사는 계정 공유, 비정상 접근, 권한 범위 초과 사용, 보안 사고 가능성이 확인되는 경우 해당 계정의 이용을 제한하거나 추가 인증, 비밀번호 변경, 권한 재검토를 요구할 수 있다.

### 8. 서비스의 내용

회사가 제공하는 서비스의 범위는 다음과 같다.

1. 반품 접수 관리
2. 반품 처리 상태 관리
3. 택배 수거/배송조회/운송장 연동
4. 센터 입고
5. 검수/판정
6. 사진/첨부파일 관리
7. 재고 반영
8. 폐기/제조사반품/외부반출
9. 고객문의/분쟁/사고 처리 보조
10. 정산 보조
11. 통계/리포트
12. API 연동
13. 알림 발송
14. 권한/계정 관리
15. 감사로그/접속로그 관리

서비스의 세부 기능, 이용 가능 범위, 계정 권한, 플랜, 연동 방식은 개별 계약, 운영정책, 서비스 설정에 따라 달라질 수 있다.

### 9. 서비스의 변경·중단·점검

회사는 서비스 안정성 확보, 기능 개선, 보안 조치, 설비 점검, 외부 연동 변경, 장애 대응을 위해 서비스를 변경, 중단 또는 점검할 수 있다.

회사는 서비스 변경, 중단 또는 점검이 이용자에게 영향을 주는 경우 서비스 화면, 공지사항, 이메일, 알림 등 적절한 방법으로 안내한다. 긴급 장애, 보안 사고, 외부 연동 장애, 통신망 장애 등 사전 안내가 어려운 경우에는 사후 안내할 수 있다.

### 10. 이용자의 의무

이용자는 다음 사항을 준수해야 한다.

1. 정확한 고객사, 상품, 반품, 운송장, 정산 정보를 입력·관리할 의무
2. 계정과 권한을 실제 업무 범위에 맞게 관리할 의무
3. 최종 고객/수취인의 개인정보를 관계 법령과 개인정보처리방침에 따라 취급할 의무
4. 반품 판정 기준, 상품 상태, 사진·첨부파일, 폐기·반출 지시를 정확하게 입력할 의무
5. 엑셀 다운로드, API 조회, 외부 반출 자료를 승인된 목적과 범위에서만 사용할 의무
6. 서비스 이용 중 발견한 오류, 오입력, 권한 오남용, 보안 사고 가능성을 회사에 알릴 의무
7. 법령, 약관, 운영정책, 개별 계약을 준수할 의무

### 11. 금지행위

이용자는 다음 행위를 해서는 안 된다.

1. 타 고객사 개인정보 또는 업무 데이터 열람 시도
2. 권한 없는 운송장 조회
3. 실제 개인정보를 테스트 데이터로 입력
4. 계정 공유, 양도, 대여
5. 무단 다운로드 또는 엑셀 반출
6. 서비스 크롤링 또는 자동화 남용
7. API 키, 토큰, 인증 정보 공유
8. 허위 반품 정보 입력
9. 악성파일 업로드
10. 시스템 보안 우회 시도
11. 경쟁 서비스 개발 목적의 무단 사용
12. 법령 위반 목적 사용
13. 서비스 운영, 네트워크, 데이터베이스, 외부 API에 과도한 부하를 주는 행위
14. 회사 또는 제3자의 권리, 명예, 신용, 영업비밀을 침해하는 행위

회사는 금지행위가 확인되는 경우 이용 제한, 계정 정지, API 제한, 자료 삭제 요청, 계약 해지 등 필요한 조치를 할 수 있다.

### 12. 반품 처리 정보의 입력 및 관리

고객사/쇼핑몰, 고객사 관리자, 대리점 담당자, 직영센터 담당자는 반품 접수 정보, 운송장번호, 상품명/옵션/수량, 반품 사유, 검수 결과, 판정 결과, 사진·첨부파일, 재고 반영, 반출·폐기 정보가 정확하게 입력·관리되도록 해야 한다.

반품 접수자료, 택배 도착 후보 자료, 실제 반품처리 원장은 서로 다른 자료이며, 서비스는 이를 구분하여 관리할 수 있다. 실제 상품, 수량, 판정, 창고, 재고 반영은 서비스에서 정한 절차에 따라 확정된다.

이용자가 입력한 정보의 오류, 누락, 지연으로 인해 업무 처리, 정산, 고객문의, 사고·분쟁 대응에 영향이 발생할 수 있으므로 이용자는 입력 자료를 주기적으로 확인해야 한다.

### 13. 택배사/API 연동

회사는 반품 접수, 수거, 배송조회, 운송장 상태 확인, 외부 접수자료 수집, 알림 발송 등을 위해 외부 시스템과 API로 연동할 수 있다.

이용자는 API 키, 토큰, 인증 정보, 연동 계정을 안전하게 관리해야 하며, 이를 제3자에게 공유하거나 승인되지 않은 목적으로 사용할 수 없다.

외부 시스템의 장애, 점검, 정책 변경, 응답 지연, 데이터 오류, 인증 만료는 서비스 이용에 영향을 줄 수 있다. 회사는 서비스 내에서 확인 가능한 범위의 연동 이력과 오류 정보를 제공할 수 있다.

### 14. 사진/첨부파일 관리

이용자는 반품 상품 사진, 포장 상태 사진, 파손 증빙, 문의 첨부파일 등을 등록할 수 있다.

이용자는 사진 또는 첨부파일에 불필요한 개인정보, 민감한 정보, 악성파일, 제3자의 권리를 침해하는 자료가 포함되지 않도록 주의해야 한다.

회사는 서비스 운영, 보안, 개인정보 보호, 저장 공간 관리, 법령 또는 계약상 필요에 따라 사진·첨부파일의 등록, 조회, 다운로드, 보관, 삭제를 제한할 수 있다.

### 15. 검수·판정·재고 반영

검수와 판정은 반품 상품의 상태, 수량, 고객사별 판정 기준, 창고 라우팅, 후속 처리 방향을 정하기 위한 업무 절차다.

반품 판정 또는 처리완료만으로 현재고가 즉시 변경되지 않을 수 있으며, 재고 반영은 일마감, 외부반출, 폐기 확정 등 서비스에서 정한 확정 절차에 따라 처리된다.

고객사, 대리점, 직영센터는 상품 상태 판정 기준, 재고 반영 기준, 폐기·제조사반품·외부반출 승인 기준을 업무 현실에 맞게 관리해야 한다.

### 16. 정산 및 이용요금

서비스 이용요금, 청구 대상, 정산 기준, 과금 항목, 지급 또는 청구 일정은 개별 계약, 요율표, 서비스 설정, 운영정책에 따른다.

서비스에서 제공하는 정산 자료, 통계, 리포트는 반품 처리 이력과 운영 데이터를 기준으로 작성되는 업무 보조 자료다. 최종 청구, 지급, 세금계산서, 비용 부담 주체, 이의 제기 절차는 개별 계약과 정산 절차에 따른다.

이용자가 요금을 기한 내 지급하지 않거나 정산에 필요한 정보를 제공하지 않는 경우 회사는 개별 계약과 운영정책에 따라 서비스 이용 제한, 연동 제한, 계약 해지 등 조치를 할 수 있다.

### 17. 데이터 보관 및 삭제

회사는 서비스 제공, 계약 이행, 정산, 고객문의, 사고·분쟁 대응, 보안, 감사 목적을 위해 필요한 범위에서 데이터를 보관할 수 있다.

고객사 계약 종료, 계정 해지, 이용 제한, 데이터 삭제 요청이 있는 경우 회사는 관계 법령, 개인정보처리방침, 개별 계약, 운영정책에 따라 데이터 반출, 보관, 삭제, 비식별화, 접근권 회수 절차를 진행한다.

업무 원장, 정산 자료, 감사로그, 보안로그, 백업 데이터는 법령, 계약, 사고·분쟁 대응, 서비스 안정성 확보를 위해 일정 기간 보관될 수 있다.

### 18. 개인정보 보호

회사는 개인정보 보호법 등 관계 법령과 개인정보처리방침에 따라 개인정보를 처리한다.

개인정보의 수집·이용, 위탁, 제3자 제공, 국외 이전, 보유기간, 파기, 사진·첨부파일, 로그, 감사로그, 엑셀 다운로드, 계약 종료 후 데이터 처리에 관한 구체적인 사항은 개인정보처리방침을 따른다.

이용자는 서비스 이용 과정에서 최종 고객/수취인, 고객사 담당자, 대리점 담당자, 직영센터 담당자 등 정보주체의 개인정보를 필요한 목적과 범위에서만 처리해야 한다.

### 19. 지식재산권

서비스, 화면, 프로그램, 데이터베이스 구조, 문서, 로고, 디자인, API 문서, 운영 매뉴얼 등에 관한 지식재산권은 회사 또는 정당한 권리자에게 귀속된다.

이용자는 회사의 사전 동의 없이 서비스를 복제, 배포, 판매, 대여, 양도, 역설계하거나 경쟁 서비스 개발을 위한 목적으로 사용할 수 없다.

이용자가 서비스에 등록한 고객사 자료, 상품정보, 반품자료, 첨부파일의 권리는 해당 이용자 또는 정당한 권리자에게 귀속된다. 이용자는 해당 자료를 서비스 이용 목적에 필요한 범위에서 회사가 처리할 수 있도록 허용한다.

### 20. 손해배상

회사 또는 이용자가 이 약관, 개별 계약, 관계 법령을 위반하여 상대방에게 손해를 발생시킨 경우 귀책 사유와 손해 범위에 따라 배상 책임을 질 수 있다.

손해배상의 범위, 절차, 한도, 면책 사유는 관계 법령, 개별 계약, 서비스의 성격, 귀책 사유, 손해 발생 경위에 따라 판단한다.

### 21. 책임 제한

회사는 안정적인 서비스 제공을 위해 노력한다. 다만, 다음 각 호의 사유로 서비스 이용에 영향이 발생할 수 있다.

1. 이용자의 입력 오류, 권한 관리 소홀, 계정 공유, API 인증 정보 관리 소홀
2. 외부 택배사, 외부 API, 통신망, 클라우드, 알림 발송 시스템의 장애 또는 정책 변경
3. 천재지변, 전쟁, 재난, 감염병, 정전, 통신장애, 보안 사고 등 회사의 합리적 통제 범위를 벗어난 사유
4. 정기점검, 긴급점검, 보안조치, 장애 복구를 위한 서비스 중단
5. 고객사, 대리점, 직영센터의 업무 지시, 상품 판정 기준, 폐기·반출 승인, 정산 기준에 따른 처리 결과

회사는 법령상 허용되는 범위에서 서비스의 성격, 개별 계약, 귀책 사유, 손해 발생 경위를 고려하여 책임 범위를 정한다.

### 22. 계약 해지 및 이용제한

이용자는 개별 계약과 운영정책에서 정한 절차에 따라 서비스 이용계약을 해지할 수 있다.

회사는 이용자가 약관, 개별 계약, 운영정책, 관계 법령을 위반하거나 서비스 운영, 보안, 다른 이용자의 권리를 침해하는 경우 서비스 이용을 제한하거나 계약을 해지할 수 있다.

계약 해지 또는 이용제한 이후의 데이터 보관, 삭제, 정산, 접근권 회수, API 연동 해제는 개인정보처리방침, 개별 계약, 운영정책에 따른다.

### 23. 개별계약과 약관의 관계

이 약관은 서비스 이용에 관한 공통 조건을 정한다. 고객사, 대리점, 직영센터 또는 기타 계약 주체와 회사 사이에 별도 서면 계약, 요율표, 운영합의, 보안합의가 있는 경우 해당 문서에서 정한 사항이 우선 적용된다.

다만, 개인정보 보호, 보안, 금지행위, 권한 범위, 법령 준수에 관한 사항은 이 약관, 개인정보처리방침, 개별 계약, 관계 법령을 함께 적용한다.

### 24. 분쟁 해결 및 관할

회사와 이용자는 서비스 이용과 관련하여 분쟁이 발생한 경우 상호 협의하여 해결하도록 노력한다.

협의로 해결되지 않는 분쟁은 관계 법령과 개별 계약에서 정한 절차에 따른다. 관할 법원은 민사소송법 등 관계 법령과 개별 계약에서 정한 기준에 따른다.
