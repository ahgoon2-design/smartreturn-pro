# 반품 AI 판정도우미 기준

## 목적

이 문서는 SmartReturn Pro에서 AI 판정도우미를 설계하거나 화면/데이터 구조에 연결할 때 따르는 기준이다.

SmartReturn의 AI는 사진/영상 자동판정이 1순위가 아니다. 1차 목적은 고객사별 판정 매뉴얼과 판정표를 기준화하고, 작업자의 판정을 빠르고 일관되게 돕는 것이다.

핵심 문장:

```text
AI는 최종 판정자가 아니라 판정지원 도우미다.
최종 판정은 작업자가 확정한다.
```

## AI 적용 우선순위

AI 적용은 아래 순서를 우선한다.

1. 고객사별 판정 매뉴얼/판정표 관리
2. 판정 체크리스트 기반 작업자 보조
3. 규칙 기반 추천 판정
4. AI 추천 사유/확인 포인트 제공
5. 사진/영상은 증빙/교육/분쟁 대응/학습자료로 우선 사용
6. 특정 고객사/특정 상품군 데이터가 충분할 때만 사진/영상 자동판별 실험

사진/영상 자동판정은 충분한 학습자료, 촬영 기준, 고객사별 상품군 기준이 갖춰졌을 때 제한적으로 실험한다. 초기 방향은 작업자가 더 빠르고 같은 기준으로 판단하도록 돕는 것이다.

## 사진/영상 자동판정이 1순위가 아닌 이유

CJ대한통운 대리점 기반 플랫폼은 고객사와 상품 종류가 매우 다양하다.

같은 “파손”이라도 고객사, 상품군, 포장 상태, 구성품 기준에 따라 양품/리퍼/제조사반출/폐기 판단이 달라질 수 있다. 사진/영상 자동판정은 특정 고객사, 특정 상품군, 충분한 판정 이력과 촬영 품질이 있을 때 의미가 있다.

초기에는 사람이 최종 판정하고, AI는 기준 확인, 체크리스트, 추천 판정, 추천 사유, 누락 확인 포인트를 제공하는 방식이 더 빠르고 정확하다.

## 판정 매뉴얼/판정표

고객사별로 판정 기준을 관리한다. 판정 항목은 공통 고정값이 아니라 고객사 설정을 우선한다.

예시:

```text
양품:
- 미개봉
- 구성품 완전
- 판매 가능 상태

리퍼A:
- 개봉 흔적 있음
- 상품 자체 사용감 거의 없음
- 재포장 후 판매 가능

리퍼B:
- 사용 흔적 있음
- 기능 정상
- 할인 판매 가능

제조사반출:
- 초기불량 의심
- 기능불량
- 제조사 확인 필요

폐기:
- 파손 심함
- 오염
- 재판매 불가

부품적출:
- 본체는 폐기 대상이나 재사용 가능한 부품이 있음
```

판정표는 `client_id`, 필요 시 `client_unit_id`, 상품군, 판정코드, 체크항목, 추천조건, 필수 증빙 기준을 함께 고려할 수 있어야 한다.

## AI 판정도우미 화면 방향

반품처리 화면에는 향후 “AI 판정도우미” 영역을 둘 수 있다. 이 영역은 작업자의 판단을 대체하지 않고, 짧고 명확하게 확인 포인트를 제시한다.

기능 예시:

- 업체 판정 기준 보기
- 상태 체크리스트
- AI 추천 판정
- 추천 이유
- 확인할 항목
- 최종 판정 적용
- 작업자 피드백 저장

상태 체크 예시:

- 미개봉
- 개봉
- 박스 훼손
- 구성품 누락
- 사용감 있음
- 파손
- 오염
- 기능불량
- 제조사 확인 필요
- 부품적출 가능

AI 추천을 적용하더라도 최종 `judgment_code`, `warehouse_id`, 처리완료는 작업자가 확정한다. `warehouse_id`가 확정되지 않은 판정은 완료할 수 없다.

## 세트상품/구성품과의 연결

세트상품 반품에서는 구성품 상태가 판정 추천에 영향을 준다.

예시:

- 필수 구성품 모두 있음 + 상품 정상 → 양품 가능
- 필수 구성품 누락 → 양품 불가, 리퍼/보류/구성품누락 추천
- 본체 파손 + 일부 구성품 정상 → 부품적출 추천

AI 판정도우미는 작업자에게 내부 BOM 용어를 과다 노출하지 않고 “구성품 확인”, “누락”, “파손”, “부품적출 가능”처럼 업무 언어로 안내한다.

## 데이터 누적

사진/영상은 우선 자동판정이 아니라 아래 용도로 사용한다.

- 판정 증빙
- 업체 공유
- 분쟁 대응
- 작업자 교육자료
- 향후 AI 학습자료

작업자 피드백, 최종 판정, 추천 판정, 추천 사유, 체크리스트 응답, 사진/영상 증빙은 향후 학습자료가 될 수 있으므로 고객사/상품/판정 scope와 함께 남긴다.

## 금지 방향

- AI를 최종 판정자로 표현하지 않는다.
- 사진/영상 자동판정을 초기 핵심 기능처럼 과장하지 않는다.
- 고객사별 판정 기준 없이 공통 AI 판정만 적용하지 않는다.
- AI 추천만으로 `warehouse_id` 없는 처리완료를 허용하지 않는다.
- 현장 작업자 화면에 복잡한 내부 모델명, BOM 용어, 기술 설명을 과다 노출하지 않는다.
