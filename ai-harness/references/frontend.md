## Rules

- 기존 화면과 공통 컴포넌트를 먼저 검색한다.
- 새 화면을 만들기 전에 기존 화면 수정 가능성을 검토한다.
- loading state를 누락하지 않는다.
- route guard와 사용자 권한 분기를 고려한다.
- build 가능 상태를 유지한다.
