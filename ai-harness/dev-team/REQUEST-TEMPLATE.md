## 3. 바로 쓸 수 있는 요청 예시

### 신규 기능

이 작업을 똘망이 방식으로 진행해줘.
실행대상은 Claude Code 또는 Codex 중 하나로 고정하고, 먼저 AGENTS.md를 읽어라.
신규 기능이므로 spec-writer로 스펙을 작성한 뒤 사용자 승인 전 구현하지 마라.
승인 후 구현하고, 테스트/build 결과와 보고서를 작성하라.
커밋/push는 금지한다.

### 버그 수정

이 버그를 똘망이 방식으로 수정해줘.
실행대상은 Claude Code 또는 Codex 중 하나로 고정하라.
작업 전 git status를 확인하고, 관련 파일만 수정하라.
수정 후 관련 테스트를 실행하거나 미실행 사유를 적어라.
보고서에는 실행/미실행/실패/남은 위험을 분리하라.
git add/commit/push는 금지한다.

### 독립 검수

이 보고서를 똘망이 검수 기준으로 독립 검수해줘.
실행대상은 Claude Code 또는 Codex 중 하나로 고정하라.
보고서 주장만 믿지 말고 실제 git status, diff, 테스트 결과, 수정 파일 범위, secret 노출 여부를 확인하라.
최종 판단은 통과/부분통과/실패/보류 중 하나로 적어라.

### 커밋 선별

현재 워킹트리를 똘망이 기준으로 선별 검수해줘.
작업별 변경 묶음을 나누고, 커밋 후보와 보류 파일을 분리하라.
git add/commit/push/stash는 하지 마라.
