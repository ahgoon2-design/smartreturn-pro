# 똘순이 사업 요청 템플릿

> 이 문서는 SmartReturn 사업용 AI 팀 "똘순이"에게 일을 맡길 때 쓰는 요청 양식이다.
> 모든 항목을 반드시 채울 필요는 없지만, 고객 공개 문서나 가격·계약·개인정보가 걸린 작업은 가능한 한 자세히 적는다.

## 1. 간단 요청 양식

아래 문장을 그대로 사용해도 된다.

요청:
- 하고 싶은 일:

목적:
- 왜 필요한가:

사용 대상:
- 내부용 / 고객 공개용 / 대리점용 / 고객사용 / 미정

원하는 결과물:
- 보고서 / 제안서 / 가격표 / 홍보문구 / FAQ / 운영정책 / 검수 / 기타

검수 강도:
- 가벼운 검수 / 풀 게이트 / 똘순이가 판단

## 2. 상세 요청 양식

### 요청 제목

예:
- CJ 대리점 대상 제안서 초안
- Basic/Pro/Ultra 가격표 검토
- 반품 영상 증거 보관 정책 설계

### 작업 목적

이 작업을 왜 하는지 적는다.

예:
- 고객사 영업에 사용할 제안서가 필요하다.
- 반품 처리 가격표를 만들기 전에 손익 위험을 확인하고 싶다.
- 사진/영상 증거를 분쟁 대응에 쓰기 위한 정책이 필요하다.

### 대상

누구에게 보여줄 자료인지 적는다.

- 내부 검토용
- 사장님 의사결정용
- 대리점 제안용
- 고객사 제안용
- 홈페이지 공개용
- 계약/약관 반영용
- 고객지원 응대용

### 필요한 산출물

원하는 결과물을 고른다.

- 시장조사 메모
- 사업계획 초안
- 제안서 초안
- 상담 스크립트
- 가격표 초안
- 손익 시나리오
- 운영 흐름도
- 예외 처리 기준
- 약관/계약 조항 초안
- 리스크 목록
- 홍보문구
- 블로그/카페 글
- 랜딩페이지 문구
- FAQ
- 클레임 대응 문구
- 검수 판정서
- 다음 실행 큐

### 현재 알고 있는 정보

아는 내용을 적는다.

- 고객 유형:
- 예상 물량:
- 현재 처리 방식:
- 문제점:
- 원하는 가격대:
- 관련 자료:
- 이미 정한 정책:
- 아직 모르는 것:

### 반드시 지켜야 할 조건

예:
- 과장 표현 금지
- 고객에게 확정 약속처럼 쓰지 말 것
- Basic/Pro/Ultra 플랜 기준 유지
- 사진/영상은 선택이지만 강력 권장으로 표현
- 법무/세무 최종 검토 필요 표시
- 내부용과 고객 공개용 문구 분리

### 걱정되는 위험

예:
- 가격이 너무 낮아 손해날까 걱정
- 고객에게 책임을 너무 크게 약속할까 걱정
- 개인정보 문제가 생길까 걱정
- 현장에서 실제로 못 돌릴까 걱정
- 대리점과 고객사 책임 경계가 애매할까 걱정

### 원하는 검수 방식

- 가벼운 검수
- business-auditor 검수
- 법무/리스크 검토 포함
- 재무/가격 검토 포함
- 풀 게이트
- 똘순이가 판단

## 3. 바로 쓸 수 있는 요청 예시

### 사업계획

SmartReturn 사업계획 초안을 똘순이 방식으로 만들어줘.
business-pm이 먼저 목적과 필요한 담당 역할을 나누고, 시장조사, 운영설계, 재무/가격, 법무/리스크, business-auditor 검수까지 거쳐 최종 보고서와 다음 실행 큐를 작성해줘.

### 영업자료

CJ 대리점 대상 제안서를 똘순이 방식으로 만들어줘.
타깃 고객, 제안 핵심, 상담 스크립트, 운영 가능성, 가격 위험, 책임 문구 위험, business-auditor 검수 결과까지 포함해줘.

### 가격표

Basic/Pro/Ultra 가격표 초안을 똘순이 방식으로 검토해줘.
건당 처리비, 월정액, 사진/영상 옵션비, 보관료, 대리점 수수료, 센터 원가, 손익 위험, 고객에게 보여줄 문구, business-auditor 검수 결과를 포함해줘.

### 운영정책

반품 사진/영상 증거 확보 정책을 똘순이 방식으로 정리해줘.
운송장 스캔, 영상 시작/종료, 보관 기간, 고객 제공 기준, 개인정보 위험, 분쟁 책임, 현장 실행 가능성, business-auditor 검수 결과를 포함해줘.

### 마케팅

SmartReturn 홍보글을 똘순이 방식으로 작성해줘.
marketing-writer가 초안을 만들고, business-auditor가 과장 표현, 고객 오해 가능성, 법무 위험 신호를 검수해줘.

### 고객지원

고객지원 FAQ를 똘순이 방식으로 만들어줘.
고객 질문, 답변 문구, 책임범위 초과 위험, 약관/운영과의 일치 여부, business-auditor 검수 결과를 포함해줘.

### 검수만 요청

아래 문서가 허술한지 똘순이 business-auditor 기준으로 검수해줘.
숫자 오류, 내부 모순, 과장/오해, 법무·개인정보 위험, 실행 가능성, 출처 유무를 기준으로 PASS / 조건부 / FAIL / 보류로 판단해줘.

## 4. 요청 시 주의사항

- 고객에게 공개할 문서는 반드시 공개용이라고 말한다.
- 가격, 계약, 약관, 개인정보, 책임소재가 있으면 반드시 말한다.
- 확정된 숫자와 추정 숫자를 구분한다.
- 모르는 것은 모른다고 적는다.
- AI가 임의로 확정하면 안 되는 부분은 "확정 금지"라고 적는다.
- 법무/세무 최종 검토가 필요한 문서는 전문가 검토 필요라고 표시한다.

## 5. 한 줄 요청

짧게 요청하고 싶으면 이렇게 말한다.

"이 일을 똘순이 방식으로 처리해줘. 필요한 담당 역할을 나누고, 초안 작성, 검수, 최종 보고서, 다음 실행 큐까지 정리해줘."
