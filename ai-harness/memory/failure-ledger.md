# 실패 원장 (failure-ledger)

## 목적
- 작업 중 발생한 실패를 기록해 같은 실패가 반복되지 않게 한다.
- 새 오케스트레이터나 새 개념을 추가하는 문서가 아니라, 발생한 실패를 남기는 최소 학습 원장이다.
- 똘망이/똘고리/똘작이/똘순이 개념은 FREEZE 상태이며 이 원장으로 확장하지 않는다.

## 사용 규칙
- append-only. 기존 항목은 삭제하지 않는다(틀린 기록은 항목 안에 정정 메모로 남긴다).
- 항목 번호는 FL-NNN(세 자리, 직전 최대 +1).
- 각 항목 형식: ID / 날짜 / 분류 / 발생한 문제 / 원인 / 재발 방지 / 다음 적용 / 상태.
- 새 SPEC 작성이나 큰 작업 착수 전 이 원장을 먼저 참조한다.
