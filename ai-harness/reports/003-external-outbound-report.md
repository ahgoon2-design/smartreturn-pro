## 확인 불가 / 사유
- **반출확정 실행 미수행(의도적)**: 후보가 기존 데이터이고 반출확정은 재고차감을 일으키므로 기존 데이터 보호 + 위험 회피로 미실행.
- **REFURB_A/B/C 후보 화면 노출**: 현 외부반출 후보에 해당 판정 건이 없어 직접 확인 불가. 깨끗히 보려면 REFURB_A 처리완료 → (창고 라우팅) → 마감 → 외부반출 후보화 필요(최소 데이터 + 창고 설정). 이번 미수행. 단 backend 테스트로 포함 검증됨.
