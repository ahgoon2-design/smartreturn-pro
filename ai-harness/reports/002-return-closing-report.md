## 확인 불가 / 사유
- **마감 확정 실행 미수행(의도적)**: 후보가 내가 만든 데이터가 아니라 기존 데이터이고, 마감확정은 재고반영을 일으키는 상태 변경이므로 **기존 데이터 보호 + 위험 회피**를 위해 실제 확정 버튼을 누르지 않음. → "마감 후 재고반영/중복 방지"는 미확인. 단 backend pytest(`confirm_return_closing` 등 80 passed)로 로직 검증됨.
- 내 처리완료 데이터로 깨끗하게 마감까지 보려면, ESPMARKETING 창고 라우팅 설정 → task#9/10 처리완료 → 마감 후보화가 필요(최소 데이터 추가 + 창고 설정). 이번엔 미수행.
