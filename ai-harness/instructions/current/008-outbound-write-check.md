# 008 - 외부반출 반출확정(쓰기) 검증

> 실행 전 `<PROJECT_ROOT>/AGENTS.md`, `CLAUDE.md`를 읽는다. 브랜치 `smartreturn-pro` 기준. main 병합/동기화 제안 금지, push 금지. 선행: 007 완료(외부반출 대상).

## 목표
`/returns/external-outbound`에서 외부반출 대상 테스트 건 1건을 **반출확정**까지 검증한다.

## 담당 화면 또는 기능
- `/returns/external-outbound` (외부반출 검수/확정)

## 사전 조건
- 007에서 일마감 완료된 외부반출 대상 테스트 건(`V3WRITE-`) 존재
- REFURB_A 또는 MANUFACTURER_RETURN 권장
- 반품관리번호 확인 가능, 테스트 식별자 확인 가능

## 실행 범위
- 테스트 외부반출 대상 **1건만** 검수/확정.
- 반품관리번호 1:1 스캔 흐름 사용.
- 다른 후보와 함께 처리하지 않는다.

## 필수 확인 항목
- [ ] 외부반출 후보에 테스트 건 표시
- [ ] REFURB_A/B/C 또는 MANUFACTURER_RETURN 후보 포함 정책 확인
- [ ] GOOD/DISPOSAL/HOLD/DEFECTIVE가 후보에 잘못 섞이지 않음
- [ ] 반품관리번호 스캔 가능
- [ ] 스캔 후 반출확정 버튼 활성화
- [ ] 반출확정 성공(외부반출상태 "확정")
- [ ] 확정 후 재고 차감/결과 안내 확인(서버 경로)
- [ ] 동일 건 중복 반출 방지

## 위험 회피 조건
- 테스트 식별자가 아닌 후보 선택/스캔 금지
- 여러 건 일괄 반출 금지
- 반품관리번호 불명확하면 중단
- 재고 차감 대상 창고 불명확하면 반출확정 금지
- 확정 버튼이 다건 대상으로 보이면 클릭 금지

## 중단 조건
- `V3WRITE-` 건만 분리 선택/스캔 불가 → 확정하지 말고 중단·보고
- 서버/브라우저 10~15분 이상 막힘 → 중단, 수동 확인 필요
- 앱 버그 발견 → 보고만, 코드 수정 금지
